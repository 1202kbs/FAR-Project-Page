Learning What to Recall:
Adaptive Multi-Cue Episodic Memory for World Models

Qualitative demo: rollout videos on LoopNav, SoundSpaces, and AI2-THOR.

Anonymous Authors

Anonymous Institution(s)

World models must recall observations seen far in the past, but fixed recall rules based on recency, pose overlap, or visual similarity can pick the wrong memory. Future-Aware Recall (FAR) trains a retriever with the future the world model is asked to predict: during training, memories that make the realized future more likely get more credit, and the retriever learns both cue-specific relevance and which cues (time, pose, vision, audio) to trust for each query. At inference it recalls without seeing the future. Below, each video shows a full return-phase rollout.

LoopNav

FAR outperforms hand-designed recall

A static outdoor Minecraft environment with procedurally generated navigation. With the same time and pose cues, FAR retrieves frames with a clearer predictive view of the goal than WorldMem, and fusing metadata with vision gives the strongest long-horizon rollouts.

LoopNav highlights

Return-phase moments from several evaluation episodes, each labeled with its clip number. Every block shows the ground-truth frame, then for FAR, Temporal, WorldMem, and LongLive-RAG the prediction and the four recalled memories with their time offsets. Red shading marks where a prediction differs from the ground truth. It is an error overlay drawn for visualization, not something the model generated. FAR reaches 20 to 40 seconds back for the frames that matter, while the baselines mostly recall the last few seconds.

SoundSpaces

FAR adaptively learns which cues to trust

Realistic indoor navigation with spatialized audio. When pose and appearance are ambiguous, for example along a long corridor, FAR learns to rely on audio to recall a memory with a clear line of sight to the goal region.

AI2-THOR

FAR recalls the right state as the world changes

Interactive household scenes where the agent moves objects between surfaces and containers, so memory holds the same place in conflicting states. FAR recalls the interaction history and renders the current state rather than a stale one.

AI2-THOR highlights

Return-phase moments from several evaluation episodes, each labeled with its clip number. Every block shows the ground-truth frame, then for each method the prediction and the recalled memories with their time offsets. A badge on each prediction says whether the rendered state matches the world the agent left behind. When the agent returns to a station it has changed, FAR recalls the frames from the interaction itself rather than a pose-matched but stale view.
